# Crusher Evo — 16-second 9:16 social ad

This sample promotes Skullcandy Crusher Evo True Black using a cinematic Remotion composition. Product images are downloaded directly from publicly listed product photography sources at CI runtime; images are **not committed to Git**. A generated original instrumental beat avoids licensing a third-party track.

## Verified facts
- Adjustable sensory bass
- Personal Sound audio customization
- Up to 40 hours battery life
- Rapid Charge: 10 minutes for 4 hours listening

Specs: [Skullcandy UAE](https://skullcandy.ae/products/crusher-evo-wireless-headphones), [noon UAE](https://www.noon.com/uae-en/crusher-evo-wireless-over-ear-headphone-with-adjustable-sensory-bass-true-black/N40839991A/p/).

## Render
```
npm install
python3 -m pip install Pillow
npm run assets:crusher
npm run audio:crusher
npm run typecheck
npx remotion browser ensure
npm run render:crusher
npm run verify:crusher
```

Open an Actions run named **Crusher Evo vertical product video** and download the artifact `crusher-evo-vertical-video`.

This is an independent promotional concept. Product images may be subject to third-party rights; obtain permissions before commercial publishing. No price shown because seller prices change.
